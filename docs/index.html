A flattened redaction box destroys the pixels under it, but not its own width. In a known font, only some words are that wide; the words around the box say which of those fit. nsx26 redacts page images properly, then measures, on prose the model has never seen, how often that is enough to guess what was hidden.

The model is overconfident: its average belief in its first guess was 0.59, its accuracy 0.47. Treat its numbers as rankings, not probabilities. Reproduce with ./unredact.sh evaluate (seed 2026, 18.7 min); every case is in results/cases.json.

  • Width alone leaves a median of 3,662 texts (one or two words) that fit a box; with the words around it the first guess is right 47% of the time, against 19% from width alone.
  • Random static instead of black: 45%. The box keeps its width either way.
  • Printed and scanned (simulated): 46%.
  • Two words under one box: 15%.
  • Names: with the 90 stand-in names merely added to the vocabulary, the first guess is right 0% of the time; an attacker who knows the box holds one of those 90 puts the right one first 25% of the time and in the top five 89%.
  • Boxes 3 px wider than the ink on each side: 0% for an attacker who assumes tight boxes, 6% for one who knows the padding (the wider width window admits more candidates).
  • Every box 160 px wide: 0%.

How it works

  1. Find the boxes. Solid dark rectangles, or rectangles of random static, located to the pixel.
  2. Read the page. tesseract reads the visible words; their widths fix the font and size by regression.
  3. Width. From a 34,499-word vocabulary, keep only texts whose ink is as wide as the box.
  4. Context. A trigram word model ranks those by the visible words before and after the box.

How to defend

  • Make every box the same width. redact.sh --uniform 160: the uniform row above.
  • Remove the text, then reflow. Redact the source document, not a picture of it, so nothing keeps its width.
  • Pad generously and unpredictably. A known pad only widens the window (pad3-known).
  • Remember lists. If an adversary can list the candidates, a name is far easier to guess than a word.

What it does not do

  • It never recovers pixels. A flattened box has none; every output is a ranked guess, labelled as one.
  • It is measured on clean, single-column, left-aligned prose in three common fonts, plus one simulated print-and-scan. Justified text, other fonts, real scans and real documents are not measured here; do not assume these numbers carry over.
  • Its word model is 19th- and early 20th-century English from Project Gutenberg. It knows that era's words, not yours.
  • It does not read PDFs. A PDF "redaction" that only draws a box over live text is a different, worse failure; rasterise and flatten.

Use it to audit your own redactions, or on documents you are entitled to examine.

Run it

git clone https://github.com/magneato/nsx26 && cd nsx26
./setup.sh                      # Ubuntu 24.04 / 26.04  (Windows 11: powershell -ExecutionPolicy Bypass -File .\setup.ps1)
./redact.sh sample page.png --book 1661 --seed 3
./redact.sh page.png -o red.png --term talk --term dear --key red.key.json
./unredact.sh red.png           # -> red.guess.json, red.guess.png
./unredact.sh score red.guess.json red.key.json
./unredact.sh evaluate          # the table above
